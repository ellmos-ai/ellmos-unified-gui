## Zero-Copyleft Guarantee & Unprivileged Execution

- Zero-Copyleft Isolation: All runtime and development components are governed exclusively by permissive licenses (MIT, BSD-3-Clause, Apache-2.0). The repository contains zero GPL, AGPL, or viral copyleft dependencies.
- Unprivileged User-Mode Operation (RunAsInvoker): Unified GUI runs entirely in unprivileged user mode (`python -m unified_gui`, port 8990 loopback on 127.0.0.1). No administrative elevation, sudo, or root privileges are required for web serving, console CLI, or test execution.

## Governance and Operational Invariants

ellmos Unified GUI strictly adheres to ten foundational governance and runtime invariants:
- INV-LOCAL-01: Network Privacy (100% Local-First / Zero-Egress: Server binds strictly to 127.0.0.1; zero outbound tracking, metrics, or telemetry)
- INV-CANON-02: Data Ownership (Single Data Canon: No duplicate domain database; views and delegates directly to canonical backends)
- INV-PROBE-03: Lifecycle (Dynamic Capability Probing: Panels activate only when probe() validates backend availability within 2s)
- INV-AUDIT-04: Compliance (Append-Only JSONL Audit Trail: Every state-changing request [POST/PUT/PATCH/DELETE] is logged to ~/.ellmos/unified-gui/audit.jsonl)
- INV-LOCK-05: Safety (Pre-Flight Permission and Lock Enforcement: Write routes check locks and permissions fail-closed via LOCK.permissions.json)
- INV-INJECT-06: Security (Untrusted Content Protection: External strings are rendered exclusively via safe text assignments and escaped templates)
- INV-MOUNT-07: Embedding (Dual-Mode Embedding Parity: Identical panel features available in standalone mode or mounted sub-app via mount())
- INV-HOST-08: Portability (Host-Neutral Paths: Standardized ~ expansion and cascading hostname configurations in unified-gui.config.json)
- INV-ZERO-09: Simplicity (Zero Frontend Build Overhead: Pure FastAPI + Jinja2 + HTMX; zero node/npm build dependencies)
- INV-SLA-10: Security SLA (48-Hour Acknowledgment & 5-Day Triage: Formal incident response commitments for security reports under § 521 BGB Gefälligkeitsrecht)
